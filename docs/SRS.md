# Software Requirements Specification — v0.1 scope
User groups: Municipal admin, MDRRMO, MSWDO, barangay staff, auditors, public visitors. Named accounts and office-scoped permissions required; not currently implemented.

Required future capabilities: immutable resident/household identifiers, dated membership transitions, incident-specific affected assessments, duplicate-review queue, situation reports, aid program and inventory provenance, verified distribution receipt, budget-reconciliation disclosures and public notices.

Count residents, families, households, assessed, affected, eligible and served as **different measures**. Every published metric needs source, filter, reporting cutoff, and verification classification. Do not represent unreceived barangay reports as zeros.

Out of scope for initial codebase: live registry entry, money movement, beneficiary approvals, real financial data imports, automatic aid adjudication, continuous citizen GPS, DSWD integration.
